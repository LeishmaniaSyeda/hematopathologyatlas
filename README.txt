HEMATOPATHOLOGY ATLAS — BY RAYAN SYED

A separate, standalone, static teaching website. No build tools, server, account, or installation are required.

WHAT'S INCLUDED
- 66 disease entities: 20 anemia topics, 19 leukemia / myeloid-neoplasm topics, and 27 lymphoma / lymphoid / plasma-cell / reactive-mimic topics.
- Microscopy foundations: red-cell morphology, marrow orientation and lymph-node architecture.
- Interactive labelled teaching schematics: red-cell shapes, a myeloblast with Auer rod, and a Reed–Sternberg-cell pattern. These are explicitly schematic illustrations, not real micrographs.
- 7 representative, source-attributed micrographs (where available) from Wikimedia Commons, with original source / licence pages linked from the site.
- 33 IHC, flow, cytochemistry and special-stain entries.
- Differential comparison laboratory, 13 spotters, 3 stepwise clinical-pathology cases and a searchable glossary.
- Bookmarks, weak-spotter tracking and learning progress stored locally in the browser.

OPEN LOCALLY
1. Extract the folder.
2. Open index.html in a modern browser.
3. Most teaching text and interactive tools work offline. Selected Wikimedia Commons micrographs are loaded from the web and need an internet connection.

FREE HOSTING: NETLIFY DROP
1. Go to https://app.netlify.com/drop and sign in / create a free account.
2. Drag the extracted hematopathology-atlas folder onto the upload area.
3. Netlify publishes the site and supplies a public URL.

FREE HOSTING: GITHUB PAGES
1. Create a public repository and upload index.html (README is optional).
2. In repository Settings > Pages, deploy from the main branch / root.
3. After deployment, GitHub provides a github.io URL.

CONTENT & IMAGE NOTES
- Educational summaries are original study notes, intended to support MBBS pathology learning with selected advanced extensions. This is a broad core atlas, not an exhaustive transcription of every rare WHO / ICC entity.
- WHO-HAEM5 is the main disease-classification framework, with selected ICC terminology differences noted. Classification criteria evolve; use current specialist references for clinical work.
- Real micrographs are displayed without fabricated arrows and link to source / licence pages. Verify the licence on the source page before reusing an image in another project or publication.
- The clickable microscopy diagrams are original teaching schematics and must not be mistaken for diagnostic specimens.
- This site is not a diagnostic tool and does not replace a pathology textbook, local laboratory standards, or specialist interpretation.

PROGRESS & PRIVACY
Disease exploration, spotter results, case completion, bookmarks and weak spotters are saved in browser localStorage on the device. Data is not sent to a server and does not sync between devices. Clearing browser data may erase it.
